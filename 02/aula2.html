Técnicas de Demonstração

Contraexemplo, demonstração por exaustão, demonstração direta, por contraposição e por absurdo. (Gersting, cap. 2.1)

1. Conjectura, contraexemplo e prova

Uma conjectura é uma afirmação P → Q que ainda não sabemos se é verdadeira. Alguns casos sugerindo que ela vale (raciocínio indutivo) não provam nada; só um contraexemplo ou uma demonstração completa (raciocínio dedutivo) decide.

Dia a dia: conhecer três pessoas simpáticas de uma cidade não prova que "todo mundo lá é simpático". Uma única pessoa mal-educada já derruba a afirmação.

Exemplo: a conjectura "para todo inteiro positivo n, n! ≤ n²" resiste até n = 3, mas falha em n = 4:

nn!n²n! ≤ n²
111sim
224sim
369sim
42416não

Um único contraexemplo (n = 4) já derruba a conjectura inteira.

def fatorial(n):
    resultado = 1
    for i in range(1, n + 1):
        resultado *= i
    return resultado

for n in range(1, 5):
    print(n, fatorial(n) <= n ** 2)

2. Demonstração por exaustão

Ideia: com número finito de casos, teste todos.

É a mesma lógica de conferir a lista de chamada de uma turma pequena: aluno por aluno, sem fórmula.

Exemplo: "se um inteiro entre 1 e 20 for divisível por 6, também é divisível por 3." Só 20 casos, então basta testar cada um:

for n in range(1, 21):
    if n % 6 == 0:
        print(n, "é divisível por 6 e por 3:", n % 3 == 0)
Variante: demonstração por casos, quebrar a hipótese em poucas partes que cobrem tudo (ex.: "x par" ou "x ímpar") e provar cada parte.

3. Demonstração direta

Ideia: suponha P, deduza Q passo a passo.

A abordagem padrão, a primeira a tentar. É o encadeamento de "se está chovendo, a rua fica molhada": um fato leva ao outro sem pular etapas.

Exemplo: a soma de dois inteiros pares é par.

Ver demonstração

x = 2m    y = 2n

x + y = 2m + 2n = 2(m + n)

x + y = 2k,   k = m + n inteiro

Logo, x + y é par.

def eh_par(n):
    return n % 2 == 0

def verificar(n, m):
  if eh_par(n) and eh_par(m):
    print(n + m)
    print(eh_par(n + m))
  else:
    print("algum dos numeros nao e par")
    return False

verificar(4, 6)
verificar(3, 6)

4. Demonstração por contraposição

Ideia: prove Q′ → P′ em vez de P → Q.

Use quando a negação da conclusão dá mais informação que a hipótese original. É o mecânico testando "se o motor não liga, a bateria está descarregada" em vez de "se a bateria carrega, o motor liga": mesma ideia, mais fácil de checar.

Exemplo: se n² for ímpar, então n é ímpar.

Ver demonstração

Contrapositiva: n par → n² par

n = 2m

n² = (2m)² = 4m² = 2(2m²)

Logo, n² é par, e a conjectura original vale.

def eh_par(n):
    return n % 2 == 0

for n in range(1, 11):
    print(n, not eh_par(n), not eh_par(n ** 2))
Não confunda com recíproca. Contrapositiva de A → B é B′ → A′ (equivalente). Recíproca é B → A, e pode ser falsa: "a > 5 → a > 2" é verdadeira, mas "a > 2 → a > 5" é falsa (a = 3).

5. Demonstração por absurdo

Ideia: suponha P e Q′ juntos, chegue numa contradição.

Ideal para provar que algo não existe. É o álibi: "se eu estivesse na festa, alguém teria me visto; ninguém viu; logo eu não estava lá."

Exemplo simples: não é possível estar na água e pegando fogo ao mesmo tempo.

Ver demonstração

Suponha P: "estar na água" e Q′: "estar pegando fogo", os dois ao mesmo tempo.

esta_na_agua = True  e  esta_pegando_fogo = True

água apaga fogo  →  as duas coisas não podem valer juntas

Contradição! Logo, não é possível estar na água e pegando fogo ao mesmo tempo.

esta_na_agua = True
esta_pegando_fogo = False

contradicao = esta_na_agua and esta_pegando_fogo
# contradicao = False

if contradicao:
    print("Contradição!")
    print("não é possível estar na água e pegando fogo ao mesmo tempo")
else:
    print("É possível")
