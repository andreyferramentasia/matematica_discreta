Para listar todos os divisores de n, testamos cada candidato de 1 até n. Dois jeitos de escrever a mesma coisa:

Com laço for

n = 8
divisores = []
for i in range(1, n + 1):
    if n % i == 0:
        divisores.append(i)
print(divisores)

Com list comprehension

n = 8
divisores = [i for i in range(1, n + 1) if n % i == 0]
print(divisores)

Saída dos dois: [1, 2, 4, 8].

Coprimos (primos entre si)

mdc(a, b) = 1 · Coprimos

Ideia: os dois não têm nenhum fator em comum além do 1.

Algoritmo de Euclides

Listar divisores fica lento para números grandes. Euclides troca o par (a, b) por (b, resto) até o resto zerar.

mdc(a, b) = mdc(b, a % b)

abDivisãoresto
42066420 = 6 · 66 + 2424
662466 = 2 · 24 + 1818
241824 = 1 · 18 + 66
18618 = 3 · 6 + 00

O último resto diferente de zero é o mdc: mdc(420, 66) = 6.

def mdc(a, b):
    while b != 0:
        a, b = b, a % b
    return a

print(mdc(420, 66), mdc(8, 15))

Saída: 6 1. A linha a, b = b, a % b troca os dois valores ao mesmo tempo. O Python já traz pronto: from math import gcd (gcd é a sigla em inglês para mdc).

O mdc como combinação linear

Para quaisquer a, b positivos existem inteiros i e j com mdc(a, b) = i · a + j · b. Os números i e j saem das divisões de Euclides, de baixo para cima.

Ver como achar i e j para mdc(420, 66) (Exemplo 30 do livro)

1. Em cada divisão de Euclides, passe o resto para o outro lado. Mesma cor = mesmo valor:

DivisãoResto isolado
420 = 6 · 66 + 24→24 = 420 − 6 · 66
66 = 2 · 24 + 18→18 = 66 − 2 · 24
24 = 1 · 18 + 6→6 = 24 − 1 · 18

2. Comece pela linha do 6 (o mdc) e troque cada número colorido pelo bloco da mesma cor:

6 = 24 − 1 · 18

6 = 24 − (1 · 66 − 1 · 2 · 24)

6 = 24 − 66 + 2 · 24

6 = 3 · 24 − 66junta os 24: um 24 sozinho + 2 · 24 = 3 · 24

6 = 3 · 420 − 3 · 6 · 66 − 66

6 = 3 · 420 − 18 · 66 − 66

6 = 3 · 420 − 19 · 66junta os 66: −18 · 66 − 1 · 66 = −19 · 66

Logo, i = 3 e j = −19.

print(3 * 420 - 19 * 66)

Saída: 6. Na aula 8 esse truque vai achar a chave privada d.

a mod n · Resto da divisão

Ideia: contar em círculo, como o relógio.

São 22h e você vai dormir 5 horas. O relógio não mostra 27h, mostra 3h: 27 mod 24 = 3.

Resumo: mod (abreviação de módulo) é o operador % do Python.

ContaDivisãoResultado

Potência com resto: o pow

No RSA a conta é sempre do tipo me mod n. O Python tem dois jeitos de fazer:

JeitoCódigoComo calcula 73 mod 15
sem biblioteca7 ** 3 % 157 · 7 · 7 = 343, depois 343 mod 15 = 13
com bibliotecapow(7, 3, 15)7 · 7 = 49 → 49 mod 15 = 4
4 · 7 = 28 → 28 mod 15 = 13

O resultado é o mesmo, mas o pow tira o resto a cada multiplicação, então o número nunca passa de n.

print(7 ** 3 % 15)
print(pow(7, 3, 15))
print(pow(123456789, 65537, 999999937))

Saída: 13, 13 e um resultado instantâneo. Com ** a última conta geraria um número de mais de 500 mil dígitos antes do %.

6. A função fi de Euler

φ(n) · Fi de Euler

Ideia: quantos números de 1 até n são coprimos com n.

Numa turma de n cadeiras, φ(n) conta os alunos cujo número de chamada é coprimo com n.

Resumo: φ(n) = quantidade de k entre 1 e n com mdc(k, n) = 1.

123456789101112

n = 12: só 1, 5, 7 e 11 são coprimos com 12. Logo φ(12) = 4.

from math import gcd

def fi(n):
    return len([k for k in range(1, n + 1) if gcd(k, n) == 1])

print(fi(12), fi(7), fi(15))

Saída: 4 6 8.

Caso 1: n primo

Ver demonstração: φ(p) = p − 1

Os divisores de um primo p são só 1 e p.

para 1 ≤ k < p: mdc(k, p) = 1

para k = p: mdc(p, p) = p ≠ 1

Logo, φ(p) = p − 1.

Caso 2: n = p · q, com p e q primos diferentes

φ(p · q) = (p − 1) · (q − 1)

É exatamente o caso do RSA. Exemplo com n = 15 = 3 · 5. Primeiro, os divisores de 15:
