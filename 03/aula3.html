Matemática Discreta · Aula 03

Quantificadores, Predicados e Validade

Quantificador universal e existencial, predicados, interpretação, simbolização e checagem de validade. (Gersting, cap. 1.3)

1. Predicado

Já vimos essa palavra no português: em "João está cansado", o sujeito é João e o predicado é "está cansado", aquilo que se declara sobre o sujeito.

PortuguêsMatemática
Sujeito: JoãoA variável x
Predicado: "está cansado"P(x): "x está cansado"

A ideia é a mesma: o predicado é o que se declara sobre x. A diferença é que, na matemática, essa declaração precisa ficar V ou F assim que x vira algo específico.

"Para todo x, x > 0" não dá pra simbolizar só com letra de proposição e conectivo (aula 1). Falta um jeito de descrever uma propriedade que depende de x: o predicado.

  • P(x) descreve uma propriedade de x.
  • Sozinho, P(x) não tem valor lógico: depende de quem é x.
  • Só vira proposição quando x recebe um valor, ou é amarrado por um quantificador.
ExpressãoTipoValor lógico
P(x): "x é par"Predicadoindefinido
P(4)ProposiçãoV
P(5)ProposiçãoF

2. Quantificador universal e existencial

Dizem quantos elementos de um domínio têm a propriedade do predicado.

(∀x)P(x) · Universal · "para todo x"

Ideia: vale para cada elemento, sem exceção.

Chamada de turma: basta um aluno faltando para "todos vieram" virar falso.

5 alunos, todos vieram:

Todos verdes → (∀x)P(x) é V.

(∃x)P(x) · Existencial · "existe x"

Ideia: basta um elemento cumprir.

Vaga de estacionamento: não precisa que todas estejam livres, só achar uma.

5 vagas, uma livre:

Um verde já basta → (∃x)P(x) é V.

O domínio muda o resultado, mesmo com o mesmo predicado:

Domínio(∀x)(x > 0)
Inteiros positivosV
Todos os inteirosF

Todo domínio precisa ter pelo menos um elemento: sem isso, "para todo x" não quer dizer nada.

3. Interpretação

Fbf (sigla do inglês well-formed formula, "fórmula bem-formulada") é uma expressão lógica escrita seguindo as regras de sintaxe do sistema, predicados, quantificadores e conectivos usados corretamente. Para uma fbf com predicado ter valor lógico, precisa de uma interpretação:

  • Domínio: a coleção de objetos, não vazia.
  • Significado de cada predicado nesse domínio.
  • Valor de cada constante (a, b, 0, 1...).

Exemplo:

  • Domínio: livros da biblioteca.
  • P(x): "x tem capa vermelha".
  • (∃x)P(x): V se existir pelo menos um livro de capa vermelha na estante.

4. Escopo e variável livre

Escopo: a parte da fórmula onde o quantificador age (os parênteses depois dele).

Pergunta para decidir: existe um ∀ ou ∃ que alcança essa variável?

  • Sim → variável presa (ou amarrada).
  • Não → variável livre.

Uma fbf com variável livre fica sem valor lógico fixo, até alguém dizer quem ela é.

(∀x)[Q(x, y) → (∃y)R(x, y)]

y em Q(x, y): livre (nenhum ∀y ou ∃y o alcança).
y em R(x, y): presa pelo (∃y).

5. Simbolização

Palavras-chaveQuantificadorConectivo comum
"todo", "para todo", "cada", "qualquer"∀→
"existe", "algum", "há pelo menos um"∃∧

Com A(x): "x é aluno" e D(x): "x é dedicado":

FraseFbf
"Todo aluno é dedicado."(∀x)[A(x) → D(x)]
"Algum aluno é dedicado."(∃x)[A(x) ∧ D(x)]

O truque de "só", "somente" e "apenas"

O que vem depois dessas palavras vira a conclusão do condicional, não a hipótese.

Aplicando o truque: "Só professores corrigem provas."

P(x)"x é professor"
C(x)"x corrige provas"

Depois de "só" vem "professores": logo P(x) é a conclusão, e C(x) é a hipótese.

(∀x)[C(x) → P(x)]

Quem quebra a promessa é sempre a pessoa "False"!

Tentativa 1

Imagine que alguém prometa:

"Se você é professor, você corrige provas."

Agora existem 4 situações:

Professor?Corrige?Quebrou?
✓ Sim✓ SimNão
✓ Sim✗ NãoSim
✗ Não✓ SimNão
✗ Não✗ NãoNão

Perceba: a promessa só quebra se alguém for professor e não corrigir. Isso obrigaria todo professor a corrigir provas, mas a frase original não disse isso.

Tentativa 2

Agora inverta, imagine que alguém prometa:

"Se você corrige provas, você é professor."

"Somente professores corrigem provas."

As mesmas 4 situações:

Corrige?Professor?Quebrou?
✓ Sim✓ SimNão
✗ Não✓ SimNão
✓ Sim✗ NãoSim
✗ Não✗ NãoNão

Perceba: a promessa só quebra se alguém corrigir provas sem ser professor. É exatamente isso que "só professores corrigem provas" quer proibir.

A tentativa 2 é a que bate com a frase original. Por isso a simbolização certa usa corrigir como hipótese: (∀x)[C(x) → P(x)], não (∀x)[P(x) → C(x)].

6. Negando quantificadores

Igual à De Morgan da aula 1 (troca ∧ por ∨), negar um quantificador troca ∀ por ∃:

Fórmula originalNegação equivalente
(∀x)P(x)(∃x)[P(x)]′
(∃x)P(x)(∀x)[P(x)]′

Negar "todos os convidados chegaram" não é "nenhum chegou", é "existe um convidado que não chegou".

dominio = [1, 2, 3, 4, 5]

def eh_par(x):
    return x % 2 == 0

lista = [eh_par(x) for x in dominio]
lista_neg = [not eh_par(x) for x in dominio]

print(lista)
print(lista_neg)

# nega (∀x)P(x)
print((not all(lista)) == any(lista_neg))

7. Validade

Análogo da tautologia (aula 1) para fbfs com predicado: é válida se for V em todas as interpretações possíveis.

AspectoTautologiaValidade
"Sempre V" em...todas as linhas da tabela-verdadetodas as interpretações
Quantos casos2ⁿ (finito)infinitos
Existe algoritmo?SimNão

Válido: (∀x)P(x) → (∃x)P(x). Todo domínio tem pelo menos um elemento, então "vale pra todos" já garante "vale pra algum".

Não válido: (∃x)P(x) → (∀x)P(x). Um contraexemplo já derruba, igual à aula 2:

dominio = [1, 2, 3, 4]

def P(x):
    return x % 2 == 0

lista = [P(x) for x in dominio]

existe_par = any(lista)
todos_pares = all(lista)

# condicional falha quando a hipótese é V e a conclusão é F
print(existe_par and not todos_pares)

Dá True: existe_par é V e todos_pares é F, então o condicional falha aqui. Mas isso só testa um domínio; nunca prova validade, só derruba.
