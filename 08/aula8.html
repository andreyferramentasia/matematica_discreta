Receita completa

from math import gcd

p = 5
q = 3
print(p, q)

def calcular_n(p, q):
    return p * q

def calcular_fi(p, q):
    return (p - 1) * (q - 1)

def calcular_candidatos(fi):
    return [x for x in range(2, fi) if gcd(x, fi) == 1]

def criptografar(m, e, n):
    return pow(m, e, n)

def descriptografar(c, d, n):
    return pow(c, d, n)

n = calcular_n(p, q)
fi = calcular_fi(p, q)
lista_candidatos = calcular_candidatos(fi)
e = lista_candidatos[0]
d = pow(e, -1, fi)
print(f"Chave pública {e, n}, Chave privada {d, n}")

m = 7
mc = criptografar(m, e, n)
print(mc)

dm = descriptografar(mc, d, n)
print(dm)

Saída: 5 3, Chave pública (3, 15), Chave privada (3, 15), 13 e 7.

Variações:

  • primos aleatórios: import sympy e p = sympy.randprime(100, 1000) (precisa instalar com pip install sympy);
  • e aleatório entre os candidatos: from random import choice e e = choice(lista_candidatos).

4. Por que é seguro

Para fatorar basta testar divisores até √n: se n = p · q com p ≤ q, então p · p ≤ n, ou seja, p ≤ √n. Para n = 143 isso é instantâneo:

n = 143
p = [x for x in range(2, int(n ** 0.5) + 1) if n % x == 0][0]
q = n // p
print(p, q, pow(7, -1, (p - 1) * (q - 1)))

Saída: 11 13 103. A chave privada caiu.

Extra: cifrando texto

Parte opcional, fora do exercício.

O RSA cifra números. Para cifrar texto, primeiro trocamos cada letra por um número usando um dicionário.

Regra: a mensagem m precisa ser menor que n.

  • O mod n só enxerga restos de 0 a n − 1: para ele, 21 e 6 são o mesmo número (21 ≡ 6 mod 15).
  • Com n = 15, uma letra valendo 21 voltaria como 6. Por isso, para texto, usamos primos maiores.

p = 11   q = 13

n = 11 · 13 = 143

φ(n) = 10 · 12 = 120

menor e coprimo com 120: e = 7

(7 · d) mod 120 = 1 → d = 103 (7 · 103 = 721 = 6 · 120 + 1)

Pública (7, 143), privada (103, 143).

from math import gcd

p = 11
q = 13
n = p * q
fi = (p - 1) * (q - 1)

e = [x for x in range(2, fi) if gcd(x, fi) == 1][0]
d = 1
while (e * d) % fi != 1:
    d = d + 1

tabela = {'a': 21, 'b': 22, 'c': 23, 'd': 24, 'e': 25, 'f': 26}
tabela_inversa = {v: k for k, v in tabela.items()}

def frase_para_numeros(frase):
    return [tabela.get(letra) for letra in frase]

def numeros_para_frase(numeros):
    return ''.join([tabela_inversa.get(m) for m in numeros])

def criptografar(numeros):
    return [(m ** e) % n for m in numeros]

def descriptografar(cifra):
    return [(c ** d) % n for c in cifra]

cifra = criptografar(frase_para_numeros('ae'))
print(cifra)
print(descriptografar(cifra))
print(numeros_para_frase(descriptografar(cifra)))

Saída: [109, 64], [21, 25] e ae. O caminho completo: letra → número → cifra → número → letra.
