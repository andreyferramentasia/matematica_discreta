1. O que é um conjunto

Já usamos essa palavra no dia a dia: um "conjunto de panelas" é uma coleção de objetos que andam juntos.

Na matemática é a mesma ideia, com duas regras a mais:

RegraExemplo

Repetir não muda nada{1, 1, 2} = {1, 2}
SímboloLeituraExemplo com A = {violeta, verde, castanho}
∈pertenceverde ∈ A

Três jeitos de descrever um conjunto

Todos abaixo descrevem S, o conjunto dos inteiros positivos pares:

JeitoComo fica
1. ListarS = {2, 4, 6, ...}
2. Recorrência2 ∈ S; se n ∈ S, então n + 2 ∈ S
3. PropriedadeS = {x | x é inteiro positivo par}

Lê-se "o conjunto dos x tais que x é inteiro positivo par". O jeito 3 costuma ser o melhor: a propriedade é um predicado, como na aula 3.

Conjuntos com nome próprio

SímboloConjunto

∅ ou { }conjunto vazio: nenhum elemento

Cuidado: ∅ e {∅} são diferentes.

  • ∅ é uma caixa vazia: 0 elementos.
  • {∅} é uma caixa que tem uma caixa vazia dentro: 1 elemento.

2. Subconjunto

A é subconjunto de B quando todo elemento de A também está em B.

A ⊆ B  significa  (∀x)(x ∈ A → x ∈ B)

A ⊆ B · Subconjunto

Ideia: A cabe inteiro dentro de B.

Suas músicas favoritas formam um subconjunto de todas as músicas do seu celular.

A ⊂ B (subconjunto próprio): A ⊆ B e sobra pelo menos um elemento de B fora de A.

Com A = {1, 7, 9, 15}, B = {7, 9} e C = {7, 9, 15, 20}:

ProposiçãoValorPor quê
B ⊆ CV7 e 9 estão em C
B ⊂ AVcabe, e sobram 1 e 15 em A
A ⊆ CF1 ∉ C
15 ∈ CV15 é elemento de C
{7} ⊂ AV{7} é conjunto, então usa ⊂, não ∈
∅ ⊆ CV∅ é subconjunto de qualquer conjunto

Em Python, os operadores de comparação testam subconjunto:

A = {1, 7, 9, 15}
B = {2, 3}
C = {7, 9, 15, 20}

print(B <= C)
print(B <  C)
print(B >= C)
print(B >  C)
PythonMatemáticaSignificadoResultado
B <= CB ⊆ CB está dentro de C (pode ser igual)False
B < CB ⊂ CB está dentro de C (tem que ser menor)False
B >= CB ⊇ CB contém C (pode ser igual)False
B > CB ⊃ CB contém C (tem que ser maior)False

Tudo dá False: 2 e 3 não estão em C, e C tem elementos que B não tem.

∈ ou ⊆?

  • ∈ liga um elemento a um conjunto: 7 ∈ B.
  • ⊆ liga um conjunto a outro conjunto: {7} ⊆ B.

Igualdade de conjuntos

Dois conjuntos são iguais quando têm os mesmos elementos. Para provar, mostre a inclusão nos dois sentidos:

A = B  se e somente se  A ⊆ B e B ⊆ A

3. Operações binárias e unárias

Par ordenado

Diferente do conjunto, no par ordenado a ordem importa: é como a coordenada de um assento (fileira, cadeira).

4. Operações em conjuntos

Todos os conjuntos em discussão ficam dentro de um conjunto universo S (o retângulo dos diagramas). Os diagramas de Venn mostram o resultado de cada operação na área pintada.

Exemplo: S = alunos da universidade, A = alunos de computação, B = alunos de engenharia de software.

OperaçãoDefiniçãoNo exemplo
A ∪ B{x | x ∈ A ou x ∈ B}quem cursa computação, engenharia de software ou ambos
A ∩ B{x | x ∈ A e x ∈ B}quem cursa os dois ao mesmo tempo
A − B{x | x ∈ A e x ∉ B}só computação
A′{x | x ∈ S e x ∉ A}quem não cursa computação

Se A ∩ B = ∅, A e B são disjuntos (não têm nada em comum). Ex.: A − B e B − A são sempre disjuntos.

Em Python, set já tem essas operações:

A = {1, 3, 5, 7, 9}
B = {3, 5, 6, 10, 11}

print(A | B)
print(A & B)
print(A - B)
print(A <= B)
PythonMatemáticaResultado
A | BA ∪ B{1, 3, 5, 6, 7, 9, 10, 11}
A & BA ∩ B{3, 5}
A - BA − B{1, 7, 9}
A <= BA ⊆ BFalse

Produto cartesiano

A × B é o conjunto de todos os pares ordenados (x, y) com x ∈ A e y ∈ B.

Analogia: combos de lanchonete. Cada combo é um par (lanche, bebida).

A × Bsucorefri
x-burguer(x-burguer, suco)(x-burguer, refri)
misto(misto, suco)(misto, refri)

2 lanches × 2 bebidas = 4 combos.

A × A se escreve A²; An é o conjunto das n-uplas (x1, ..., xn) de elementos de A.

from itertools import product

lanches = {"x-burguer", "misto"}
bebidas = {"suco", "refri"}

combos = set(product(lanches, bebidas))
print(combos)
print(len(combos))

5. Conjuntos enumeráveis e não enumeráveis

A cardinalidade |S| é o número de elementos de um conjunto finito. Ex.: |{2, 5, 9}| = 3.

Analogia: uma fila com senhas 1, 2, 3, ... Um conjunto infinito é enumerável se dá para distribuir senhas de modo que todo elemento seja chamado em algum momento.

ConjuntoEnumerável?Fila
ℕSim0, 1, 2, 3, ...
Pares positivosSim2, 4, 6, 8, ...
ℚ+ (racionais positivos)Sim1/1, 2/1, 1/2, 1/3, 3/1, ...
Reais entre 0 e 1Nãonenhuma fila chama todos (Cantor)
